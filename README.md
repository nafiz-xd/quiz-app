# Quiz App 🧠

A general knowledge quiz — 10 questions about Bangladesh, science, geography and the world.

## 🔗 Live Demo
👉 https://nafiz-xd.github.io/quiz-app/

## ✨ Features
- 15-second timer per question
- Progress bar and question counter
- Instant right/wrong highlighting
- Final score with a verdict — play again to beat it

## 🛠️ Tech
HTML • CSS • JavaScript — single page, hosted on GitHub Pages.
